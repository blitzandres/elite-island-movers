# Elite Island Movers

Static landing page for a moving company serving Victoria, BC and Vancouver Island:
services, pricing and contact sections, plus schema.org `MovingCompany` markup.

- **Project page:** https://andresblitz.com/projects/elite-island-movers/

## Files

- `index.html`: the live landing page
- `ELITE.html`: earlier version of the page
- `eim1.png`, `eim2.png`: images

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Contact details in the page are placeholders (`(250) XXX-XXXX`). Fill in the
business's own contact info before publishing.
