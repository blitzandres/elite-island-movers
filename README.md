# Elite Island Movers

Static one-page website for a moving company serving **Victoria, BC** and Vancouver Island — services, pricing, contact sections and schema.org `MovingCompany` markup.

- **Project page:** [andresblitz.com/projects/elite-island-movers](https://andresblitz.com/projects/elite-island-movers/)
- **Pages demo:** [blitzandres.github.io/elite-island-movers](https://blitzandres.github.io/elite-island-movers/)
- **Built by:** [Andrés Blitz](https://andresblitz.com/) · [@andresblitz](https://x.com/andresblitz)

## Tech stack

HTML · CSS · Local business JSON-LD · GitHub Pages

## Files

- `index.html` — live landing page
- `ELITE.html` — earlier draft
- Image assets in-repo

## Run locally

Open `index.html` in a browser, or serve the folder briefly with any static server.
